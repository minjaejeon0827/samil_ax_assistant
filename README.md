# Aurora 판단 데스크 — 인플루언서 계약·캠페인 집행 AI 운영 시스템

AX 인재전쟁(삼일PwC) 과제 **02 인플루언서 계약과 캠페인 집행**을 구현한 결과물입니다. 가상기업 Aurora 그룹, 기준일은 2026-07-01입니다.

전속계약 갱신 통보나 캠페인 확대 기안이 들어오면, 시스템이 **실질 공헌이익 · 13주 현금 하회 구간 · 승인 권한 · 광고 규제 · 공급 여력**으로 다시 판단합니다. 그다음 맞는 결재자에게 결재를 올리고, 결정 후의 부서 작업 · 외부 통보(모의 또는 전자결재·메신저 웹훅, v1.21) · 상태 변경까지 이어서 처리합니다. 다른 자동 갱신 계약(물류·대행사)은 계약서를 올리면 조항을 뽑아 같은 엔진으로 판단합니다(v1.21). v1.22에서는 스캔 PDF(글자 인식)·영문 계약서·LLM 계약서 요약(값·판단은 계속 규칙), 결재 뒤 AI 설명 보관함, SSO 로그아웃, 실패한 전자결재 전송 다시 보내기, 분당 토큰 한도 대응을 더했습니다. v1.23에서는 IdP가 먼저 끊는 로그아웃(Back-Channel), 서버 여러 대의 공동 토큰 한도, 스캔 PDF 진행 표시·자원 한도, 조항 문구 변형·외화 금액 처리를 더했습니다. v1.24에서는 '확인 필요'로 멈춘 계약에 확인한 값을 넣어 다시 판단하는 흐름, 계약서 요약 평가, 응답 헤더로 토큰 한도 자동 조정을 더했습니다.

## 바로 실행
```bash
cd frontend && npm install && npm run dev     # http://localhost:5173 (백엔드 없이 동작, 새로고침해도 유지)
```
왼쪽 **사건 접수**의 ①정상 → ②조건 변경 → ③정보 부족·승인 거절 버튼을 순서대로 누르고, 상단 **결재자 역할**을 바꿔 가며 결재합니다.

전체 스택·Docker·MCP·AXHub 배포는 [`docs/LEADER_GUIDE.md`](docs/LEADER_GUIDE.md)를 보세요.
