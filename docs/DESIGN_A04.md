## 3. 대표 실행 사례

- **상황·근거·대안 확인 후 생성·갱신되는 계획·작업·상태, 그 결과가 다음 판단에 반영되는 위치**: CEO가 조건변경 통보를 승인하면 작업 4건이 생기고 연계 기안 001~003이 '상위 계약 대기'가 됩니다. 계약 담당이 발송을 완료하면 계약이 '발송·회신 대기'로 바뀌고, 다음 판단(역제안)의 맥락이 됩니다. CEO가 역제안을 거절하면 계약은 '미갱신 결정'이 되고, 연계 기안 판단 규칙(`TERMINATED_STATUSES`)에 따라 001~003이 자동 부결됩니다.
- **운영 중 AI의 역할·입출력·사용 위치**: 입력은 사건 텍스트와 원본 데이터, 출력은 결정 패키지입니다. 계산·권한은 규칙 엔진이 맡고, AI는 정책 RAG 검색, 승인자용 설명문, LLM-as-a-Judge 검수(근거 없는 수치 검출, 재생성 1회), 카피 규제 판정(1단 키워드 + 2단 RAG 근거)을 담당합니다. 사람은 결재 버튼으로 결정하고, 도구(커맨드·옵저버)가 작업·발송·상태를 처리합니다.
- **예상 효과 산정 방식과 가정·제약**: 금액 효과는 산정하지 않았습니다(표본 × 풀스케일 금지). 효과는 결재자 변경 건수, 보류·부결 건수, 기한 내 결정 여부로만 셉니다. 비용·시간 제약으로 기한(7/17·8/14·9/11), covenant 30억, 리드타임 12주를 유지했습니다.

## 5. 실행·재현 방법

- **위치·접근**: 소스 zip `aurora-campaign-desk/` (AXHub 배포 시 앱 주소 추가)
- **도구·버전**: Node 22 · React 18.3.1 · TypeScript 5.6 · Vite 5.4 · Python 3.12~3.13 · FastAPI 0.162 · LangGraph 1.2 · langchain-core 1.7 · faiss-cpu 1.15 · PyMySQL 1.2 · mcp 2.3 · pytest 9.1
- **실행**: 브라우저만 쓰려면 `cd frontend && npm install && npm run dev` 후 http://localhost:5173 접속. 전체 스택은 `cd backend && pip install -r requirements-dev.txt && uvicorn app.main:app --port 8000`(+ 프론트 `.env`에 `VITE_ENABLE_API=1`). 단일 컨테이너는 `docker build -t aurora-desk . && docker run -p 8000:8000 -e API_KEYS=demo-public-key aurora-desk`
- **원본·추가 데이터**: 원본은 `data/raw/`(내용 수정 없이 파일 단위로만 분리), 가정·합성·모의는 `data/assumptions/`, 계산 결과는 `data/derived/`, 브라우저용은 `python scripts/build_dataset.py`로 재생성
- **대표 사례 실행 순서**: 왼쪽 '사건 접수'의 1→2→3 버튼 순서대로 누릅니다. 결재는 상단 '결재자 역할'을 바꿔서 합니다(시연 스크립트 `docs/templates/demo_script.md`)
- **변경 조건·모의 회신 입력**: '재무: 연체 채권 회수 불확실', '에이전시 역제안 수신', '에이전시 지급 일정 회신' 버튼. 또는 `POST /api/events`, `POST /api/replies`, MCP `inject_event`·`receive_mock_reply`
- **E2E 재현**: `bash e2e/run_all.sh`(빌드와 E2E 32묶음 296개, 약 28분. 4차는 MariaDB가 설치돼 있으면 테스트가 직접 띄움). 결과는 `e2e/reports/`에 저장됩니다
- **결과 확인 위치**: 결재 서류(이력·생성 작업), 오른쪽 부서 작업·상태 기록·채널 발송함·감사 로그, `GET /api/snapshot`
- **초기화·제약**: 상단 '처음부터'(localStorage 초기화) 또는 `POST /api/reset`. 메모리 저장소는 서버 재시작 시 초기화되므로 `REPO_PATH` 또는 MySQL을 쓰세요. 시계는 앞으로만 진행됩니다.
