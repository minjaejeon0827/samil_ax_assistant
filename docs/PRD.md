## 3. 문제 정의

### 3.1 현재 무엇이 막히는가 (원본으로 확인한 사실)
1. **배분이 성과와 반대로 간다.** 광고비 집행 비중 1위 혜인(INF-001, 40.6%)이 표본 실질 공헌이익 **10위/10**(실질 ROAS −0.20)이다. 비중 순위와 성과 순위의 스피어만 상관은 **−0.33**이다. 이번 확대 기안에서도 혜인 요청 비중이 28.0%로 1위다.
2. **보고 지표가 실제와 다르다.** 2026H1 GMV는 **+8.1%** 성장했지만, 실질 공헌이익은 **−39.6%**(표본)다.
3. **결정이 따로 움직인다.** 확대 기안(1.8억)만 부결하고 전속계약(28억)을 방치하면 7/17에 자동 갱신된다. 두 건의 기한이 같은 날이지만, 승인 권한 구간은 다르다(기안은 Masil 대표, 계약은 CEO/이사회).
4. **현금 하회를 아무도 모른다.** 재무팀 공식 전망은 최저 54.7억으로 문제가 없어 보인다. 하지만 AR·AP·발주 스케줄을 직접 합산하면 **7/21~8/21(24영업일) covenant 30억 하회**, 최저 16.48억(7/27)이다. 그 구간에 현금이 나가는 신규 약정은 **금액 불문 그룹 CEO 승인** 사항인데, 25건 중 12건이 해당한다.
5. **광고 카피 위반 위험(확장):** 인플루언서 콘텐츠의 의약품 오인 표현, 기능성 표방, 광고 표시 누락이 사전에 걸러지지 않는다.

## 8. 업무 모델

**객체:** 인플루언서 · 캠페인 · 전속계약 · 확대 기안 · 광고 카피 · 현금 전망 · 처리 건(Case) · 결재(Approval) · 작업(Task) · 발송(Message) · 감사(Audit)

**관계:** 인플루언서 1–N 캠페인 1–1 기안 1–1 카피 · 전속계약 1–N 기안(하위 집행분) · 기안 정산일 ↔ 현금 하회 구간 · 캠페인 제품군 ↔ SKU 재고·생산 라인

**처리 건 상태(State 패턴):**
```
접수 → 분석 중 → 승인 대기 ─승인→ 승인 → (작업 생성)
                 │           └거절→ 거절·부결 → (대안 작업)
                 ├→ 확인 필요 ─회신(외부) / 확인 작업 완료(내부)→ 재분석
                 ├→ 수정 필요 ─수정→ 재분석            (확장: 카피)
                 ├→ 상위 계약 대기 ─계약 결정→ 보류 유지 / 부결 / 해제→재분석
                 └→ 차단 / 재입력 요청                  (check_input)
승인 대기·승인 ─조건 변경→ 재검증 대기 → 재분석(권한 상향 시 승인 무효)
미결정 + 기한 경과 → 기한 경과 자동 확정(묵시적 승인 = 승인 없는 체결)
```

**계약 상태:** 갱신 통보 접수 → 조건변경 통보 승인 → 발송·회신 대기 → 역제안 검토 → 미갱신 결정 → 미갱신 통보 발송 → 종료 합의 (기한 경과 시 자동 갱신)
